# Quẻ hôm nay – app Android

Cách lấy file APK (không cần cài gì trên máy):
1. Tạo một repository mới trên GitHub, tải toàn bộ thư mục này lên.
2. Vào tab **Actions** → workflow **Build APK** tự chạy (khoảng 3–5 phút).
3. Mở lần chạy đã xong (dấu ✓ xanh) → mục **Artifacts** → tải **QueHomNay-apk** → giải nén ra `app-release.apk`.
4. Mở file .apk trên điện thoại Android, cho phép "Cài ứng dụng không rõ nguồn" nếu được hỏi.

Hoặc mở thư mục này bằng Android Studio → Build → Build APK.
